# Online Book Store (PHP + MySQL)
CS2307 – Internet Programming Lab Mini Project

## Run (XAMPP/WAMP)
1. Copy folder `bookstore` into `htdocs`.
2. Start Apache + MySQL. Open phpMyAdmin → Import `database.sql`.
3. Visit http://localhost/bookstore/setup_admin.php once (creates admin), then delete that file.
4. Open http://localhost/bookstore/

Admin login: admin@books.com / admin123

## Features
Register/Login (hashed passwords, sessions), search & filter, cart, checkout (transaction), order history, admin add/delete books.
